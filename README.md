# Sanctuary-art

Public visual asset repository for the **Sanctuary Soul-Healing Estate** (`sanctuary-quest.com`).  
Assets are served via GitHub Pages at:

`https://lrdysbad-debug.github.io/Sanctuary-art/<filename>`

---

## 1. File Naming Convention

All filenames use **lowercase letters and hyphens only** (no spaces or parentheses):

* **Motif Rooms:** `[motif]-[room-descriptor].jpg` *(e.g., `pr-bedroom.jpg`, `lh-front-gate.jpg`)*
* **Alternate / Variant Takes:** Append a number at the very end before `.jpg` *(e.g., `lh-recreation-room1.jpg`)*
* **Tier B Protected Path Precinct:** `path-[room-descriptor].jpg` *(protected from user/motif overrides)*
* **V · I · S Host Portraits:** `vis-[persona]-[mood].jpg` *(e.g., `vis-wl-neutral.jpg`)*

## 5. Image Optimization Guidelines
* **Room Backgrounds:** `1920x1080` (16:9), `.jpg` or `.webp`, target **under 450 KB** for instant room/Dyson Sphere transitions.
* **V · I · S Portraits:** `512x512` (1:1), `.jpg` or `.png`, target **under 100 KB**.
